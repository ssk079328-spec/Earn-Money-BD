# 💰 Earn Money BD - Telegram Mini App

একটি আধুনিক এবং রিয়েল-টাইম টেলিগ্রাম মিনি অ্যাপ, যা ব্যবহারকারীদের বিজ্ঞাপন দেখে এবং রেফার করে টাকা আয় করতে সাহায্য করে। এই প্রোজেক্টে **Monetag SDK** এবং **Node.js (Express)** ব্যাকেন্ড ব্যবহার করা হয়েছে।

## ✨ ফিচারসমূহ

- **Real-Time Balance Update:** বিজ্ঞাপন দেখার সাথে সাথে ব্যালেন্স আপডেট হয়।
- **Rewarded Ads:** মনিটেগের হাই ইসিপিএম (eCPM) রিওয়ার্ডেড অ্যাড ইন্টিগ্রেশন।
- **Daily Reward:** ২৪ ঘণ্টার লিমিট সহ প্রতিদিনের বোনাস সিস্টেম।
- **Refer & Earn:** ইউজারদের জন্য রিয়াল-টাইম রেফারেল লিঙ্ক কপি এবং সোশ্যাল শেয়ারিং অপশন।
- **Professional UI:** চলন্ত হেডলাইন (Marquee) এবং আধুনিক গ্লাস-মরফিজম ডিজাইন।
- **Secure Backend:** MongoDB এবং Render ব্যবহার করে নিরাপদ ডাটাবেস ম্যানেজমেন্ট।

## 🛠 প্রযুক্তি (Tech Stack)

- **Frontend:** HTML5, CSS3, JavaScript (Telegram Web App SDK)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Ad Network:** Monetag (In-App & Rewarded Interstitial)
- **Hosting:** GitHub Pages (Frontend) & Render (Backend)

## 🚀 কিভাবে সেটআপ করবেন

### ১. ব্যাকেন্ড (Render)
- গিটহাব থেকে কোডটি ক্লোন করুন।
- `index.js` ফাইলে আপনার `mongoURI` এবং `botToken` পরিবর্তন করুন।
- Render-এ কানেক্ট করে ড্যাপ্লয় করুন।

### ২. ফ্রন্টএন্ড (GitHub Pages)
- `index.html` ফাইলে `apiBase` ভেরিয়েবলে আপনার রেন্ডার ইউআরএল দিন।
- মনিটেগ থেকে আপনার নিজস্ব `data-zone` আইডিটি আপডেট করুন।
- GitHub Pages-এ হোস্ট করুন।
